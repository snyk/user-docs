# Phase 3: Gain visibility

After the [Phase 2: Configure your Organization](../phase-2-configure-your-organization/) phase is complete, you can import your repositories to scan your applications.

When you import your repositories, Snyk scans the contents to find all supported files, such as open-source manifest files, code files, and IaC configuration files, and creates Projects from them. For details, visit [Import Projects](import-projects.md).

Optionally, add Project attributes to filter and organize your Projects when you create collections.

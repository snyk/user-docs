# Infrastructure as code

For Snyk IaC, you can integrate with [Terraform Cloud](https://docs.snyk.io/developer-tools/integrations/snyk-ci-cd-integrations/terraform-cloud-integration-for-snyk-iac-using-run-tasks/how-to-use-the-terraform-cloud-integration-for-iac) to run `snyk iac test` as part of a run workflow, in addition to scanning Terraform and YAML files in your source control repositories.

For instructions on how to implement Snyk per IaC type in the Snyk CLI, visit [Snyk CLI for IaC](https://docs.snyk.io/developer-tools/snyk-cli/scan-and-maintain-projects-using-the-cli/snyk-cli-for-iac).

# Snyk Learn reporting

{% include "../../../.gitbook/includes/deprecatedsnyk-is-deprecati....md" %}

{% hint style="info" %}
**Feature availability**

Snyk Learn organization reports are available only with Enterprise plans. Snyk Learn assignment reports and program reports are available only in the Learning Management add-on offering.

For more information, visit [plans and pricing](https://snyk.io/plans/).
{% endhint %}

Snyk Learn offers reports to help you track learning progress across your Snyk Tenant.

Use [organization-level reports](organization-reports.md) to understand how your teams engage with Snyk Learn content in each Organization. Team leads and security champions can use these reports to track the progress of their teams.

You can use the [assignments report](assignment-reports.md) to track individual [Snyk Learn assignments](../snyk-learn-assignments.md).

For insights into the overall performance and engagement of your security education and training program, use [program reporting](program-reporting.md) in the Snyk Web UI.

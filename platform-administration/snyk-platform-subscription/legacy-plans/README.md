# Legacy plans

{% hint style="warning" %}
The pages in this section cover legacy Enterprise plans. The Snyk Platform Subscription is the default Snyk Enterprise plan. For details, visit [How the Snyk Platform Subscription works](../snyk-platform-subscription-mechanics.md).
{% endhint %}

Use these pages if your contract includes a plan or licensing structure that predates the Snyk Platform Subscription:

* [Snyk Platform Access plan](credits-for-the-snyk-platform-access-plan.md): a test-based consumption plan for Snyk Code, Snyk Open Source, Snyk Container, and Snyk IaC. The plan reached end of sale in January 2026.
* [SKU-based licensing usage settings](usage-settings.md): how to view test usage and contributing developer counts for capabilities licensed through SKUs.

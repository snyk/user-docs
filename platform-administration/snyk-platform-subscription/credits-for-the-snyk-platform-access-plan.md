# Credits for the Snyk Platform Access plan

{% hint style="warning" %}
You can no longer purchase or enroll in this plan.
{% endhint %}

The Snyk Platform Access plan is now end-of-sale (as of January 2026). It is a trial of test-based consumption pricing that unifies Snyk Code, Open Source, Container, and IaC under a single license. Under this model, you pay a flat per-developer platform access fee and an up-front commitment of credits to consume for testing across Snyk Code, Open Source, Container, and IaC capabilities.

This is a different Enterprise plan from the Snyk Platform Subscription. For more information, see [Enterprise contract types](enterprise-contract-types/). For more information on how credits work under the Snyk Platform Access plan, visit [Snyk Platform Access policies](https://snyk.io/policies/definition-of-snyk-platform-access/).

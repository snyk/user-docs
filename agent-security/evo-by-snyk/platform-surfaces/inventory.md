# Inventory

Inventory surfaces the AI assets discovered across your environment alongside the assessed risk so you can review it in context.

* [AI-SPM](../ai-spm/ai-asset-visibility.md) discovers assets in your source code through a source code management (SCM) integration.
* [Agent Supply Chain Security](../agentic-development-security-ads/agent-supply-chain-security.md) within ADS discovers the components that agents use on end users' machines.

You can explore Inventory with Evo chat. For example, ask which assets occur most often in your code.

The **Repositories** table shows the Snyk Organization for each repository. If you import a repository into multiple Snyk Organizations, Snyk lists it once for each Organization.

{% hint style="info" %}
Inventory shows the assets you can access. If your access is restricted to specific Organizations, Inventory shows only the assets belonging to those Organizations, and counts and totals are lower than they are for a user with access to the whole Tenant. To learn more, visit [Access and authentication](../access-and-authentication.md).
{% endhint %}

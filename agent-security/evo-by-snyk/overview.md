# Evo by Snyk

The Evo platform provides a shared set of surfaces that present discovered AI assets and associated risk, manage policy, and report on your security posture.

Evo surfaces risk context for the assets that AI Security Posture Management (AI-SPM) and Agent Supply Chain Security discover. You apply that risk context in your policies, and Evo raises an issue when an asset violates a policy.

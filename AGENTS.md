# AGENTS.md

Instructions for AI coding agents working in `snyk/user-docs`.

## This repository is a read-only copy

`snyk/user-docs` does not publish docs.snyk.io. It is a read-only copy of the published content, updated automatically by pull requests from the source repository, `snyk/user-docs-internal`. GitBook syncs docs.snyk.io with the source repository, not with this one.

- **Do not edit files, push branches, or open pull requests here.** Anything written here is overwritten by the next update and never reaches the site.
- **Make documentation changes in `snyk/user-docs-internal`.** Content lives under `docs/<section>/` there, and that repository's `AGENTS.md` describes its structure, generated files, and pull request rules.
- **The only pull requests expected here are the automated update pull requests**, from branches named `promote/<sha>`. They are reviewed and merged by the Docs team.

## Reading this repository

You can read this repository to look up published content. Each top-level directory with a `SUMMARY.md` matches one section of docs.snyk.io, and the files match `docs/<section>/` in the source repository.

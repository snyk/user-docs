# Snyk Platform credits

### Credits for the Snyk Platform Subscription plan

The Snyk Platform Subscription plan consolidates capabilities and features into a single license for quick, flexible deployment. You can use your credits across all generally available Snyk capabilities. The Tenant Admin can enable or disable each capability by navigating to **Settings** under the Tenant section in the Snyk Web UI.

Snyk announces any changes to rates, including new products or pricing adjustments, 30 days in advance through the [Billing and Usage](https://app.gitbook.com/s/IgtgtomLQ2TUgSKOMSAm/snyk-hierarchy/usage-settings#billing-and-usage) dashboard available in the Snyk Web UI for admin users.

For more information on how credits work and the available capabilities on the Snyk Platform Subscription plan, visit the [Credit-based billing policy](https://snyk.io/policies/credit-based-billing/).

### Credits for the Snyk Platform Access plan&#x20;

{% hint style="info" %}
Customers can no longer purchase or enroll in this plan.
{% endhint %}

The Snyk Platform Access plan unifies Snyk Code, Open Source, Container, and IaC under a single license to simplify security management. This lets you deploy instantly and respond rapidly to security incidents and evolving threats.

This gives you full access to the Snyk platform and allows you to use the credits as needed. Snyk announces any changes to rates, including new products or pricing adjustments, 30 days in advance through the [Billing and Usage](https://app.gitbook.com/s/IgtgtomLQ2TUgSKOMSAm/snyk-hierarchy/usage-settings#billing-and-usage) dashboard available in the Snyk Web UI for admin users.

For more information on how credits work and the Snyk Platform Access plan, visit the [Snyk Platform Access Policies.](https://snyk.io/policies/definition-of-snyk-platform-access/)

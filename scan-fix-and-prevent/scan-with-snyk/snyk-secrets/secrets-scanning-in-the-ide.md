# Secrets scanning in the IDE

{% hint style="info" %}
Snyk Secrets supports Visual Studio Code, Visual Studio, JetBrains IDEs, and Eclipse.
{% endhint %}

Find exposed secrets as you work with Snyk Secrets in your IDE. Select your IDE for setup instructions and scan guidance.

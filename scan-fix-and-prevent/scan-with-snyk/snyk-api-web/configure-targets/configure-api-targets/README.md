# API targets

API targets scan endpoints defined in your API schema (OpenAPI, Postman Collection, GraphQL, RAML, or Bruno Collections). The scanner tests all endpoints from the schema, ensuring complete coverage of your API surface:

* [Configure Postman Collection targets](configure-postman-collection-targets.md) - Set up targets using Postman Collections
* [Configure RAML targets](configure-raml-targets.md) - Set up targets using RAML specifications
* [Configure signed requests](configure-signed-requests.md) - Configure request signing for APIs that require it
* [Configure message level encryption](configure-message-level-encryption.md) - Set up encryption for API message payloads
* [Configure an API target with a Bruno Collection](../configure-authentication/configure-an-api-target-with-a-bruno-collection.md) - Set up targets using Bruno Collections
* [Configure an API target without a schema file](configure-an-api-target-without-a-schema-file.md) - Set up targets without specifying a schema
